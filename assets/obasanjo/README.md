# Obasanjo Visual Set

Production-ready, white-background visuals of Chief Olusegun Obasanjo for the
website. Three families, one consistent likeness (broad face, gold-rimmed
glasses, patterned fila cap, white agbada). Start with `contact-sheet.jpg`
for the full overview.

All masters are ~2K (2048-2560px on the long side). Downscale freely; never
upscale the web-ready files. The `4k/` folder holds print-grade versions of
the three flagship assets.

## Notes

- Vector and pixel files are PNG (flat color, lossless). Statue photography
  is JPEG q92.
- Vector/pixel backgrounds are pure white (RGB ≈ 255); statue shots sit on a
  soft studio white (~RGB 244-250) with a natural reflection — don't butt them
  directly against `#FFFFFF` UI without a container, or crop above the
  reflection.
- Generated with Higgsfield (Nano Banana Pro / Seedream 4.5) from reference
  photography and the client's statue video; likeness anchored on multiple
  reference photos of Obasanjo (2014 portrait, 2002 agbada, 1977 + General-era
  military portraits).
